# Y.Tube v2.4.3

- Open a copied YouTube video or Shorts link from a confirmation prompt when Y.Tube comes to the foreground.
- Choose a source caption track and request automatic translation into 20 languages, including Arabic. The video needs an existing caption track that YouTube can translate.
- Improve Android TV remote focus, navigation and player controls, and reduce video compositing work on TV.
- Include the v2.4.2 fix for the channel Live tab when upgrading from v2.4.1.

## Before publishing

Verify the release APK for package `com.tensei.ytxtube`, version `2.4.3`, build `244`, and the same signing certificate as the previous release. Test an upgrade and the copied-link prompt, translated captions, and remote navigation on devices. Device checks were not completed in the development environment.
